# Energia

>*"Onde a pura intenção precede a própria criação."*

## Natureza do Elemento

A **Energia** é a manifestação física da pura força de vontade; uma potência sutil que precede a própria matéria. Ela representa a gênese de qualquer fenômeno elementar, condensando o pensamento do conjurador em forças tangíveis como o fogo devorador, a eletricidade sibilante, o gelo estático, a luz prismática, ou mesmo manifestações orgânicas como toxinas, fumaça e flora hiperativa. 

Trata-se do elemento mais volátil, expansivo e direto do espectro arcano. Sua natureza é intrinsecamente inventiva, moldando o invisível para subjugar o ambiente.

## Aplicações Práticas

A versatilidade da Energia permite que conjuradores sintonizem suas mentes para criar uma vasta gama de efeitos. Abaixo estão listadas as principais progressões de feitiços divididas por propósito tático.

### Ofensiva
*Magias focadas em causar dano direto, destruição de alvos ou negação de área através da força bruta elementar.*

| Intenções | Descrição Arcana |
| :--- | :--- |
| **Bola de Fogo** | Concentração de calor que culmina em uma explosão de chamas ao impacto. |
| **Raio** | Um raio de eletricidade linear concentrado, capaz de transpassar armaduras. |
| **Chuva de Estacas de Gelo** | Fragmentos criogênicos projetados em alta velocidade para empalar o alvo. |
| **Meteoro** | Fragmentos de pura rocha superaquecida invocados do éter em rota de colisão. |
| **Feixe de Luz** | Um vetor de luz concentrada que queima e cega instantaneamente quem cruzar seu caminho. |
| **Tornado** | Um minitornado de vento pressurizado que age como lâminas invisíveis. |
| **Rajada de Vento** | Uma onda de choque de vento condensado que empurra e atordoa os inimigos. |
| **Chicote de Plasma** | Um filamento de pura energia elétrica usado para flagelar alvos à distância. |
| **Rajada de Veneno** | Um jato de energia corrosiva que derrete defesas e equipamentos orgânicos. |
| **Jato de água sob pressão** | Um jato de agua corrente em alta pressão. |

### Utilidade
*Magias projetadas para alteração de terreno, invocação de construtos elementares e manipulação do ambiente.*

| Intenções | Descrição Arcana |
| :--- | :--- |
| **Cortina de Fumaça** | Manifestação de uma névoa densa e escura que bloqueia completamente a linha de visão. |
| **Névoa Tóxica** | Nuvem de fumaça venenosa que asfixia e debilita criaturas na área. |
| **Pólen Paralisante** | Esporos vegetais bioenergéticos que travam o sistema nervoso de quem os inalar. |
| **Broto Instantâneo** | Criação uma planta ou vinha para obstruir passagens ou escalar muros. |
| **Forja do Golem de Lava** | Aglutinação de energia térmica e rocha amorfa em um servo semi-senciente. |
| **Invocação Elemental** | A personificação de um elemento puro (Ar, Fogo, Terra, Água, etc.) sob a forma de um aliado temporário. |
| **Flash de Luz Cegante** | Uma sobrecarga luminosa projetada para desorientar e cegar temporariamente um grupo. |
| **Ponte de Gelo** | Congelamento instantâneo da umidade para criar superfícies transitáveis sobre abismos ou água. |
| **Voar** | Dispara rajadas de vento continuo sobre os pés e mãos. |
| **Criar Cola** | Com o conhecimento suficiente sobre o material, permite criar componentes complexos, como por exemplo uma cola. |

### Suporte
*Efeitos utilitários de baixa intensidade voltados para a sobrevivência, distração, alteração sutil do campo de batalha ou primeiros socorros básicos.*

| Intenções | Descrição Arcana |
| :--- | :--- |
| **Acender Fogueira** | Produção de uma pequena chama para acender fogueiras ou tochas. |
| **Indução Térmica Culinária** | Geração de calor brando focado, ideal para aquecer rações e ferver água. |
| **Limpar Feridas** | Geração de água fria purificada para limpar ferimentos e aliviar queimaduras. |
| **Película Deslizante** | Criação de uma fina camada de água ou óleo para tornar o terreno mais escorregadio. |
| **Aromas Ilusórios** | Emissão de fragrâncias e odores específicos para atrair predadores ou disfarçar rastros. |
| **Ressonância Acústica** | Criação de ondas sonoras no ar para simular passos, vozes ou rugidos distantes. |
| **Sinalizador Luminescente** | Uma pequena esfera de luz flutuante contínua que serve como lanterna ou sinal de resgate. |

| **Estática Estonteante** | Uma leve carga elétrica que causa espasmos involuntários, interrompendo ações de foco de um alvo. |
| **Eco de Distração** | Estalos secos de som gerados no ar para fazer com que uma criatura olhe para a direção oposta. |

## A Lei da Volatilidade Arcana

> **Mecânica de Jogo:** A Energia permite a **criação** pura do elemento, mas não concede o **controle** pós-conjuração. 
>
> Uma vez manifestada e projetada no mundo físico, a Energia comporta-se de acordo com suas propriedades naturais e caóticas, tornando-se indistinta entre aliados, inimigos ou o próprio conjurador.
>
> * **Exemplo Prático:** Ao arremessar uma *Lança de Fogo*, o projétil seguirá uma trajetória retilínea. Qualquer criatura — seja um aliado cruzando a linha de tiro, ou um combatente próximo ao ponto de impacto — sofrerá os danos colaterais da explosão. Se o feitiço aplicar a condição de *Queimadura*, ela será infligida indiscriminadamente a todos os envolvidos na área de efeito. O fogo não reconhece lealdade.
