# Novidades do Arcádia

> Registro de atualizações em linguagem simples, para quem acompanha o livro — não é um log técnico de commits.
> Cada task concluída via `/task` adiciona um item aqui, sob a data do dia. Este arquivo alimenta o aviso automático no Discord.

## 2026-09-07

- Agora dá pra entrar no site com a sua conta do Discord, sem precisar criar senha. Também é possível vincular ou desvincular o Discord da sua conta a qualquer momento em Configurações → Contas Vinculadas.
- Chegou o bot de Discord do Arcádia! Use `/rolar` para fazer testes do sistema (2D12, ou os 2 melhores de 3D12 quando tiver Talento) e `/ataque` para rolar o dano das suas armas — tudo direto no chat do servidor, sem precisar abrir o site.
